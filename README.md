# Plantilla

A small Next.js App Router starter using Bun, TypeScript, Tailwind CSS 4, Geist, and Lucide icons. It starts in dark mode and includes a manual light/dark toggle.

## Run locally

```bash
bun install
bun run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Check the project

```bash
bun run lint
bun run build
```

The page and layout live in `src/app/`. The header and theme toggle live in `src/components/`. Replace the `test-3` branding and add destinations for the Work and Contact links when adapting this starter.
